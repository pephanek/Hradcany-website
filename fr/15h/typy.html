Les types du cinquième dessin sur le 15h

Le cinquième dessin des Hradčany porte, selon les positions, différentes combinaisons de types de plusieurs éléments du dessin. Pour la valeur 15h, ce sont les types à spirale et à barre qui comptent.

→ Voir les timbres eux-mêmes pour toutes les positions typées

Types à spirale (Is / IIs)

Il existe deux types de spirale — ouverte (Is) et fermée (IIs). Sur les planches I et II dominent les spirales fermées, ce qui rend recherchés les timbres à spirale ouverte issus de ces planches. Les planches III–VI ont la spirale ouverte.

PlanchePositions à spirale ouverte Is
Planche I2, 21, 22, 23, 49, 83, 91, 92, 94
Planche II15
Planches III–VItoutes les positions
Planche VII49, 96 très rares

Types à barre (Ip / IIp / IIap)

La longue barre se trouve dans la partie gauche du timbre, à côté de la deuxième spirale en partant du bas. Le type Ip (barre courte) occupe l’immense majorité des positions ; le type IIp (longue barre) est plus rare et possède encore le sous-type IIap.

TypePlanche et positions
IIpPlanche I : 2, 4, 5, 15, 17, 91  ·  planche II : 75, 78  ·  planche VII : 13
IIapPlanche I : 1, 12, 16, 23  ·  planche II : 8  ·  planche VII : 93

Toutes les positions indiquées sont signalées dans la galerie des positions.
